# Code of Conduct

## Our standard

We are committed to providing a welcoming, respectful, and constructive
community for everyone, regardless of background or experience.

Expected behaviour includes:

- Respectful and professional communication.
- Constructive technical criticism.
- Focusing on the issue rather than the person.
- Accepting feedback and differing viewpoints.
- Respecting project scope and documented design constraints.

Unacceptable behaviour includes harassment, discrimination, personal attacks,
trolling, sexualized language or imagery, and publishing private information
without consent.

## Enforcement

Project maintainers may remove comments, close issues or pull requests, or
restrict participation when behaviour violates this code.

Report concerns privately to the repository owner through GitHub. Reports will
be reviewed fairly and confidentially where possible.

This code applies in all project spaces, including issues, pull requests,
discussions, reviews, and community channels.
