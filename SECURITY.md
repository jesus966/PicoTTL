# Security Policy

## Supported versions

Only the latest published release receives security fixes.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository.
If that option is unavailable, contact the repository owner privately through
GitHub.

Please include:

- A clear description of the vulnerability.
- The affected version or commit.
- Reproduction steps or a proof of concept.
- The potential impact.
- Any suggested mitigation.

Please allow reasonable time for investigation and remediation before publicly
disclosing the issue.

## Scope

This policy covers the PicoTTL source code, build system, release automation,
and official precompiled firmware distributed by this repository.
